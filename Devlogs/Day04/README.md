# 4일차 — 01_Title 및 Scene 전환

**날짜**: 2026-09-23
**단계**: 1단계 · 개발 기반 구축
**상태**: 완료 · 일부 Play 항목 미확인

---

## 1. 목표

타이틀 화면의 새 게임·이어하기·설정·게임 종료 버튼을 만들고 `SceneFlow`와 연결한다. 이어하기 버튼은 저장 파일이 있을 때만 활성화한다. 기획서 12.3 기준이다.

타이틀은 게임 상태를 들고 있지 않는다. 버튼을 누르면 전역 서비스에 판정과 전환을 요청만 한다.

---

## 2. 구현 내용

### 2.1 스크립트

| 스크립트 | 역할 |
|---|---|
| `TitleScreen` | 버튼 4개 동작, 이어하기 활성 판정, 누르는 순간 모든 버튼 잠금 |
| `ConfirmDialog` | 예/아니오 확인창. 다른 화면에서도 재사용한다 |
| `SettingsPanel` | 볼륨 3종(마스터·배경음·효과음) 슬라이더. 닫을 때 저장 |
| `TitleUIBuilder` | 에디터 메뉴 `Project P > Build Title UI`. 타이틀 UI를 코드로 조립한다 |

`AudioManager`에 `GetVolume` / `SetVolume`을 추가했다. 설정 화면이 `SettingsData`를 직접 고치지 않고 서비스에 요청하게 하기 위함이다(CLAUDE.md 절대 규칙 1).

### 2.2 버튼 동작

| 버튼 | 동작 |
|---|---|
| 새 게임 | 저장이 있으면 "기존 진행을 지우고 새로 시작할까요?" 확인 → 새 저장 생성 → `02_MainHub` |
| 이어하기 | 저장 파일이 있을 때만 활성 → `02_MainHub` |
| 설정 | 볼륨 설정창. 슬라이더를 움직이면 즉시 적용되고, 닫을 때 `settings.json`에 저장한다 |
| 게임 종료 | 게임 종료 (에디터에서는 Play 종료) |

### 2.3 UI 기술 결정

| 항목 | 결정 | 이유 |
|---|---|---|
| UI 방식 | uGUI + TextMeshPro | 이후 전투 HUD와 기술 통일 |
| 입력 모듈 | `InputSystemUIInputModule` | 프로젝트가 새 Input System 전용이라 기존 모듈은 동작하지 않음 |
| 기준 해상도 | 1920×1080, Match 0.5 | 기획서 10.1 공란 → 레거시 옵션표 기본값 |
| UI 생성 | 에디터 메뉴로 자동 조립 | Canvas·버튼 구조를 씬 파일에 손으로 쓰기엔 복잡하고 오류 위험이 크다 |

### 2.4 한글 폰트

Windows에 설치된 **맑은 고딕을 참조만 하는** 동적 폰트 에셋을 만들고 TMP 설정의 fallback으로 등록했다. 폰트 파일을 내려받거나 프로젝트에 복사하지 않아도 한글이 표시된다.

**개발용 임시 조치**다. 맑은 고딕이 없는 환경에서는 한글이 표시되지 않으므로, 출시 전에 배포 가능한 폰트(Noto Sans KR 등)로 교체한다.

### 2.5 TextMeshPro 필수 리소스

조립 메뉴가 처음 실행될 때 `Assets/TextMesh Pro/`에 TMP 필수 리소스를 가져왔다(81개 파일, 약 14MB). TMP 기본 설정과 기본 폰트가 들어 있는 표준 리소스다.

## 3. 검증

### 3.1 컴파일

Unity 내장 컴파일러로 게임 빌드와 에디터 빌드(조립 도구 포함)를 모두 컴파일했다. 오류·경고 0건. 조립 도구가 이름으로 연결하는 필드 16개도 스크립트의 실제 필드명과 모두 일치하는 것을 확인했다.

### 3.2 에디터·Play 모드 (실행 기록과 파일로 확인)

- 조립 메뉴 1회차에 TMP 리소스를 가져오고, 2회차에 한글 fallback 등록과 UI 생성 완료
- `01_Title`의 참조 필드 16개가 모두 연결된 상태로 저장됨, `EventSystem`은 새 입력 모듈 사용
- Boot → `01_Title` 전환, `settings.json` 생성 (**3일차 미확인 항목 일부 해소**)
- 새 게임 → `save.json` 생성 → `02_MainHub` 전환
- 저장 파일에 `hasSuspendedSession: false`로 기록됨
- 한글 글자 누락 경고 없음

### 3.3 미확인

실행 기록으로 판단할 수 없어 따로 확인이 필요한 항목이다.

- 이어하기 버튼 활성·비활성 표시와 동작
- 저장이 있을 때 새 게임 확인창의 예/아니오
- 설정에서 바꾼 볼륨이 재실행 후 유지되는지
- 버튼 연타 시 전환 1회
- 게임 종료 버튼
- 3일차 잔여: Dev Scene에서 Play 시 Boot 경유 복귀, 손상 파일 백업, 초기화 실패 표시

## 4. 참고 사항

- **크래시 복구 폴더**: 3일차 자동 검증 중 Unity가 크래시한 뒤 에디터를 열면서 `Assets/_Recovery/`가 생겼다. 프로젝트 내용이 아닌 백업이라 삭제했고, 앞으로 커밋되지 않도록 `.gitignore`에 추가했다.
- **동적 폰트 에셋 변경**: 한글 폰트 에셋은 새 글자가 쓰일 때마다 파일(약 2MB)이 바뀐다. 커밋 시 이 변경만 섞여 있으면 되돌려도 된다.
- **`SceneTemplateSettings.json`**: Unity가 자동 생성한 표준 프로젝트 설정 파일이라 함께 커밋한다.
- **조립 도구 재실행 주의**: 메뉴를 다시 실행하면 씬에서 직접 다듬은 배치가 사라진다.
